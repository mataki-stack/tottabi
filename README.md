# 🚐 とったび ＆ とったび日和 動画検索ナビ

YouTubeチャンネル **「とったび」**（メイン）と **「とったび日和」**（サブ）の全動画（1,400本以上）を、キーワード（タイトル・概要欄・あーちゃん日記）・ハネムーンのシーズン別・日本全国47都道府県＆世界各国マップから素早く検索・管理できるローカルWebアプリです。

## ✨ 主な機能

1. **🌏 ハネムーン（新婚旅行・世界一周）シーズン別グルーピング**
   - ハネムーン Season 1 〜 Season 6、ハネムーン序章（沖縄＆タイ編）、海外旅・番外編＆総集編ごとにグルーピング表示。
   - メインチャンネル「とったび」の本編だけでなく、**同期間にサブチャンネル「とったび日和」で公開された旅の裏側Vlogも自動的に同じシーズンに統合して時系列順で一覧・連続視聴**できます（チェックボックスで本編のみ／日和含むを切替可能）。
   - シーズンごとの視聴進捗バー＆「シーズン一括視聴済み」ボタン付き。

2. **🗾 47都道府県タイルマップ ＆ 🌍 世界各国マップ絞り込み**
   - **日本全国47都道府県インタラクティブマップ**：都道府県タイルや地方ブロックをクリックすると、日本一周旅や国内車中泊・グルメ旅の該当動画を即座に一覧表示します。概要欄の「日本一周○日目は○○県」や「あーちゃん日記」からも都道府県を自動抽出しているため、タイトルに県名がない動画も検索できます。
   - **世界各国マップ（39カ国・地域）**：アジア、中東・中央アジア、ヨーロッパ、アフリカ、オセアニア・北米の国旗カードからワンクリックで絞り込み可能。

3. **🔍 タイトル・概要欄・あーちゃん日記・マイメモの高速全文検索**
   - スペース区切りで **AND検索**（例: `スイス 登山`、`山形 ラーメン`、`車中泊 大雨`）、`|` 区切りで **OR検索**（例: `モルディブ|サントリーニ`）に対応。
   - マッチした箇所をカード上でハイライト表示します。

4. **✅ 視聴済み・★ お気に入り・🕒 後で見る・📝 マイメモ管理（ローカル永続保存）**
   - サーバー側の `data/user_state.json` とブラウザの `localStorage` の両方に自動保存されます。
   - JSONファイルとしてのバックアップ書き出し・読み込みにも対応しています。

5. **🔄 APIキー不要の最新データ同期（yt-dlp）**
   - 画面右上の「🔄 最新データ同期」ボタンから、APIキー不要でいつでも最新の投稿動画や再生リストを取り込めます（高速差分同期は約5〜8秒）。

---

## 🚀 起動方法

ターミナルで以下を実行すると、ローカルWebサーバーが起動し自動的にブラウザで開きます（デフォルト: `http://127.0.0.1:8765`）。

```bash
./start.sh
```

または `uv` で直接起動できます：

```bash
uv run python app.py
```

### オプション
- `--port 8080` : ポート番号を変更して起動
- `--no-browser` : ブラウザを自動で開かずに起動
- `--sync` : 起動時にYouTubeから最新データを同期してから起動
